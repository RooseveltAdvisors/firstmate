## S1 cleanup-candidates labels kinds

$ bin/fm-fleet-view.sh --cleanup-candidates
# Cleanup Candidates

Home: /tmp/fm-lab.2HS8N0

| ID | Kind | Persistence | Teardown |
| --- | --- | --- | --- |
| crew-b | ship | disposable | bin/fm-teardown.sh crew-b |
| mate-a | secondmate | persistent | retire only by an explicit decision naming this home - see .agents/skills/secondmate-provisioning |

A persistent home is retired only by a decision naming that exact home; an idle queue is healthy, not finished.
This report prints no runnable retirement command, so retiring a standing home has to be typed deliberately.
Teardown takes one target per invocation.
