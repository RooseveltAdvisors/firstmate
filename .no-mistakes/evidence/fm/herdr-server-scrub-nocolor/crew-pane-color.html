A crew pane must not inherit the launcher's NO_COLOR

Every pane below was created by the real backend adapter (container_ensure → create_task) from a launcher running under NO_COLOR=1, exactly as an agent-started Firstmate does, and then ran the same two commands a crew agent would run: eza -l bin/backends and rg -n NO_COLOR docs/tmux-backend.md. Left column = base ecfe0719. Right column = this branch 87a5ee4a. Panes captured verbatim (tmux capture-pane -p -e / herdr pane read --format ansi).
