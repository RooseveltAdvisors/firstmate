Ship-done acceptance gate, walked through the operator CLI (bin/fm-done-guard.sh).
Fixture: a real git worktree pushed to a LOCAL bare remote (nothing is written to
the real repository); origin's URL then names the task's real repository so both the
repo-identity check and the PR reads are genuine. PRs 4961 (open) and 4960 (closed)
are read LIVE from github.com/kunchenguid/firstmate at run time.
